# 换装工坊 · 主站集成版

对应主站路径：`frontend/public/avatar/`（构建后随静态资源一起发布，访问 `/avatar/`）

与上一级 `studio/`（独立运行版）的区别：

| 差异 | 说明 |
| --- | --- |
| `?embed=1` | 隐藏工坊自带侧栏，用于嵌进主站「用户 → 换装工坊」 |
| 接口前缀 | 请求走 `/avatar-api/*`，由主站反代到工坊服务的 `/api/*` |
| `avatar-import.js` | 一键导入头像：Canvas 384px 压缩、空白检测、失败重试、`postMessage` 通知主站 |
| `style.css` | 嵌入模式下去掉外层留白，与主站排版对齐 |

## 主站侧接线（3 处）

| 文件 | 改动 |
| --- | --- |
| `features/user/UserPage.tsx` | 6 个侧栏项中的「换装工坊」入口 + iframe 嵌入 + 消息监听 |
| `styles/user.css` | 侧栏第 5 项的样式 |
| `public/avatar/*` | 本目录文件 |

主站与工坊的数据通过 `postMessage({ type: 'omc:avatar-updated' })` 联动：导入成功后主站刷新头像。
